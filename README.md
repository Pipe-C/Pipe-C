## 🚀 Proyectos destacados

### 🏦 [PascuaBank](https://github.com/Pipe-C/PascuaBank)

**Sistema bancario digital desarrollado como proyecto académico.**

Monorepo enfocado en la construcción de una API bancaria con **NestJS, TypeScript, Prisma y PostgreSQL**, incluyendo:

- Operaciones atómicas para evitar condiciones de carrera.
- Manejo de montos en centavos para evitar errores de precisión.
- Auditoría inmutable de transacciones.
- Arquitectura organizada por capas.
- Frontend con **React, Vite y Tailwind CSS**.
- Entorno completo mediante **Docker Compose**.
- Documentación de API con **Swagger / OpenAPI**.

---

### 💰 [miNatillera](https://github.com/Pipe-C/miNatilleraHackatonKiro)

**Aplicación Serverless para gestión financiera colectiva.**

Proyecto desarrollado para el **Kiro AI Hackathon**, utilizando:

- **Spring Boot 3.3 + Java 21** sobre AWS Lambda.
- **AWS SnapStart** para optimizar los cold starts.
- **API Gateway + DynamoDB** utilizando un diseño Single-Table.
- **AWS SAM** como infraestructura como código.
- **S3 + URLs firmadas** para almacenamiento de comprobantes.
- **CloudFront** para distribución del frontend.
- Frontend con **React, Vite y Tailwind CSS**.
- Exportación de reportes a Excel e imágenes.

🔗 [Ver demo](https://d2a4sb8pl2c18.cloudfront.net/)

---

### 🛡️ [Laboratorio-XSS](https://github.com/Pipe-C/Laboratorio-XSS)

**Laboratorio interactivo de seguridad web enfocado en XSS y Session Hijacking.**

Incluye demostraciones prácticas de vulnerabilidades y sus respectivas contramedidas:

- Cross-Site Scripting (XSS).
- Session Hijacking.
- Sanitización mediante **DOMPurify**.
- Protección de cookies mediante `HttpOnly`.
- Buenas prácticas de desarrollo seguro alineadas con **ISO/IEC 27001:2022 — A.8.28 Secure Coding**.
- Construido con **React, Vite y Tailwind CSS**.
