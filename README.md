### 🚀 Proyectos Destacados

#### 🏦 [PascuaBank](https://github.com/Pipe-C/PascuaBank)
**Sistema Bancario Digital (Monorepo)** — Proyecto académico para la I.U. Pascual Bravo.
* **Backend & Persistencia:** Desarrollado con NestJS, TypeScript y Prisma ORM. Implementa operaciones atómicas en BD para evitar condiciones de carrera, montos en centavos para precisión matemática y auditoría inmutable de transacciones.
* **Frontend:** Desarrollado con React 18, Vite y Tailwind CSS, con arquitectura en capas y validaciones de negocio en el cliente.
* **DevOps & Docs:** Despliegue en Docker Compose (PostgreSQL + NestJS + Nginx) y documentación de API interactiva expuesta con Swagger / OpenAPI.

#### 💰 [miNatillera (Kiro AI Hackathon)](https://github.com/Pipe-C/miNatilleraHackatonKiro)
**Aplicación Serverless de Gestión Financiera Colectiva** [Demo en vivo](https://d2a4sb8pl2c18a.cloudfront.net/)
* **Backend Serverless:** Construido con Spring Boot 3.3 (Java 21) desplegado sobre AWS Lambda con SnapStart para optimización de cold starts, API Gateway y DynamoDB (Single-table design).
* **Infraestructura como Código:** SAM (Serverless Application Model) para el aprovisionamiento de recursos en AWS (S3 para comprobantes con URLs firmadas, CloudFront para CDN y Budgets).
* **Frontend:** Desarrollado con React 18, Vite, Tailwind CSS v4, soporte offline y exportación de reportes a Excel e imágenes.

#### 🛡️ [Laboratorio-XSS](https://github.com/Pipe-C/Laboratorio-XSS)
**Entorno Interactivo de Secuestro de Sesión y Desarrollo Seguro**
* Demostración práctica y guiada de vulnerabilidades de Cross-Site Scripting (XSS) y Session Hijacking alineada con el control **ISO/IEC 27001:2022 (A.8.28 — Secure Coding)**.
* Implementación de contramedidas de desarrollo seguro utilizando sanitización con **DOMPurify** y mitigación del acceso a cookies mediante la bandera **HttpOnly**.
* Construido con React 18, Vite y Tailwind CSS.
